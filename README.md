# Olive UI Clone – Frontend Assignment

This project is a pixel-perfect recreation of the Olive app landing page based on the provided assignment screenshots. The goal was to accurately translate a visual design into a fully responsive and functional frontend.

---

## Live Demo

[https://olive-clone-reactjs.vercel.app]

## GitHub Repository

[https://github.com/moreashish23/olive-clone-reactjs]

---

## Features

* Pixel-perfect UI matching the provided design
* Fully responsive across mobile, tablet, and desktop screens
* Clean and reusable component-based architecture
* Modern UI/UX practices with proper spacing and alignment
* Interactive elements with hover effects
* Optimized layout for different screen sizes

---

## Tech Stack

* React (Vite)
* Tailwind CSS
* JavaScript (ES6+)

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/your-username/olive-ui-clone.git
cd olive-ui-clone
```

### 2. Install dependencies

```
npm install
```

### 3. Run the development server

```
npm run dev
```

---

## Responsiveness

The application is designed using a mobile-first approach and tested across:

* Mobile devices (320px and above)
* Tablets (768px and above)
* Desktop screens (1024px and above)
